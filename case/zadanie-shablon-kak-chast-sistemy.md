# Методическая памятка: Шаблон как часть системы требований

## Задание 1. Приказ о зачислении + Приказ об отчислении (пп. 4.2.6.2.2.1.3, 4.2.6.2.5.1.4)
- Реестр атомарных требований, источники, аудит дефектов ЧТЗ.
- Выделение общего паттерна «Приказ по группе обучения» и таблицы отличий без дублирования.
- Карта данных с правилами поведения при отсутствии данных и ограничениями ручного ввода.
- Прямая и обратная матрицы трассировки + проверка полноты.
- Тест-кейсы (позитивный, негативный, граничные, отсутствие данных).

## Задание 2. Акт сдачи-приёмки оказанных услуг (п. 4.2.6.2.6.1.4, табл. 432, табл. 439)
- Реестр атомарных требований, классификация плейсхолдеров (общие / вариативные / специфичные), дефекты ЧТЗ.
- Единый паттерн + таблица отличий по 4 вариантам договора (2-, 3-СЗН, 3-Работодатель, 4-сторонний).
- Обоснование на 3 примерах и аргументированный ответ, почему 4-сторонний вариант не является копией 3-стороннего с добавленной строкой.
- Разрешение противоречия по заполнению ФИО подписывающего лица, трассировка, тест-кейсы (минимум 6) и Приложение А.
